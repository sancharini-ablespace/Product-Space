# Plans

Longer-form plans live here: a feature that spans several sessions, a migration with more than one
step, an investigation whose reasoning is worth keeping. One Markdown file per plan, named for the
work (`MOVE_OVERLAYS_TO_PRIMITIVES.md`, not `plan2.md`).

What does not go here:

- **Conventions** — they are skills in `.claude/skills/`, so the rule arrives with the task.
- **Architecture** — `CLAUDE.md`.
- **The design spec** — `design/README.md` and `design/design-system-readme.md`.

A plan records decisions and their reasons, and what is done versus pending. When the work lands,
either delete the plan or cut it down to the decisions that still explain the code.
